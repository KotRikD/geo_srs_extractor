Как работатс:
1. Ставим `uv`
2. Редактируем `src\dlc_geo_exporter\config.py` (туда скармливайте чё вам нужно вытащить)
3. Запускаем `uv run run.py` (Это создаст нужный venv, поставт зависимостей, ну короче uv круто)
4. Смотрим папку `output`, там всё будет (это можно использовать для приложений, которые пережёвывают plain списки, например [awg-manager](https://github.com/hoaxisr/awg-manager) для кинетика)
